## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Recipe Browser** | Full offline recipe database based on Craft Helper's data |
| **Material List** | Auto-generate a gathering list for any planned craft |
| **Base Planner** | Plan base construction material requirements in advance |
| **Session Notes** | Add personal notes and material tracking per ongoing build |
